Optimized for Every Machine

Profile A — Older PC / Laptop

CPU-only inference (ai-edge-litert). 256MB SHM buffer. 2–4 cameras at 3–5 FPS.

RECOMMENDED

Profile B — Standard Desktop

Intel/AMD VAAPI or Google Coral TPU. 512MB SHM buffer. 4–8 cameras at 5–10 FPS.

GPU ACCELERATED

Profile C — Advanced Server

NVIDIA GPU with TensorRT / CUDA. 1024MB SHM buffer. 8–16 cameras at 15–30 FPS.

ENTERPRISE

Profile D — AI Cluster

Multi-GPU acceleration + Ollama LLM sidecar. 2048MB SHM buffer. 16–64+ cameras.
